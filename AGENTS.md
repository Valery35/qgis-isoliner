# AGENTS.md — рабочий контекст Isoliner

Этот файл лежит в корне репозитория и читается первым в начале любого нового
чата. Клонируешь репозиторий, читаешь этот файл - и ты полностью в курсе, без
реконструкции по памяти. Единственный источник правды - этот репозиторий, а не
переписка. Если что-то изменилось в коде или процессе, правка идёт сюда.

## Что это

QGIS-плагин Isoliner. Группа инструментов Processing для интерполяции точечных
данных и построения изолиний на калийных месторождениях (ВКМКС, КрII).
Чистый Python/NumPy, ядро - порт GSLIB KB2D. Совместимость QGIS 3.16 - 4.99.
Версия и канонический changelog - в `grid_isolines/metadata.txt`.

Не называть это «портом ArcGIS» нигде в коде, документации, описаниях.

## Карта модулей (grid_isolines/)

| `tests/` | pytest smoke/покрытие |

## Девять инструментов (= `ALGORITHMS` в algorithms.py)

Две группы Processing: **Грид и изолинии** (основной поток) и
**Дополнительные инструменты** (категориальный индикаторный + гидрогеология).

1. `Kriging2DAlgorithm` (kb2d) - 2D Kriging: точечный/блочный, снятие тренда, стандартная ошибка, отсев ураганных проб
2. `CategoricalIndicatorAlgorithm` (kb2d) - категориальный индикаторный кригинг
3. `RasterToIsolinesAlgorithm` (isolines) - изолинии из растра
4. `ExperimentalVariogramAlgorithm` (kb2d) - экспериментальная вариограмма
5. `VariogramMapAlgorithm` (kb2d) - вариограммная карта / анизотропия
6. `CrossValidationAlgorithm` (kb2d) - кросс-валидация (leave-one-out)
7. `ExampleWellsAlgorithm` - демо-скважины (поля кровли/мощности/содержания, MINTYPE, head)
8. `ProfilesAlgorithm` - профили обработки
9. `FlowGradientAlgorithm` (hydro) - гидравлический градиент и направление потока

## Сборка и релиз

- **ZIP всегда `grid_isolines.zip`**, без суффикса версии.
- Перед упаковкой вычистить `__pycache__/` и `*.pyc`.
- Исходник руководства - в корневой папке `manual/`: `manual.md` (RU),
  `manual_en.md` (EN), папка `images/`, `build_pdf.sh`. Эти файлы **не** входят
  в плагин (zip собирается из `grid_isolines/`).
- PDF (RU и EN) пересобирать **всегда, когда правился `manual.md`**, и отдавать
  без напоминания: `cd manual && ./build_pdf.sh`.
- Скрипт кладёт результат в `grid_isolines/doc/Isoliner.pdf` и `…/Isoliner_en.pdf` -
  только эти PDF уходят в плагин.
- Лендинг (`site/isoliner_landing.html`): держать число карточек = числу инструментов.
- Структура репозитория: в корне `README.md`, `README.en.md`, `AGENTS.md`,
  папки `grid_isolines/` (плагин), `manual/` (исходник руководства) и
  `site/` (лендинг `isoliner_landing.html`, в плагин не входит).

## Стиль руководства (RU)

- Сжатая литературная техническая проза.
- Названия элементов интерфейса - **жирным**, не «ёлочками».
- В прозе нет тире и точки с запятой. В changelog точка с запятой допустима.
- **Запрещённые слова: «честный», «честнее».** Заменять на «корректнее», «правильнее».
- В кавычках держать: «наггет», «бычьи глаза».
- Заголовки: каждый инструмент `# Инструмент …`, подтемы `##` / `###`.
- В PDF нет крупного титульного заголовка документа.
- `metadata.txt`: никогда сырой `%` - писать «процент» или `%%`.
- Разделители в README: RU использует ` - ` (дефис), EN ` — ` (тире).

## Журнал решённых багов (НЕ возвращать)

- Полигонизация поясов: только GEOS `unaryUnion` + `polygonize`. НЕ `native:splitwithlines` - на густой сети терял грани, покрытие падало вдвое.
- Гауссова модель вариограммы: принудительный минимальный наггет (устойчивость, без отрицательных весов).
- Бергштрихи депрессии: знак `WHEN @vr < @vl THEN -1` (перевёрнут после проверки в QGIS).
- Определение языка: русский только при русской локали, английский для всех прочих и неопределённой.
- Слой изолиний - над полигонами; переставлять отложенно только узел полигонов, линии не трогать.
- Степенная модель: «радиус a» = показатель ω (0<ω<2), авто=max/3 к ней не применять.
- Вариограммная карта: при главном радиусе ≤ ~3×ячейки анизотропия недостоверна - сообщать «изотропно / не определено».

## Соседний проект (для общего контекста)

Geoconstructor (загрузка скважин из MS SQL, анализ ГДЯ). Ключевой структурный
факт: **номера скважин не уникальны между шахтными полями** - нужен составной
ключ или пространственный join.
