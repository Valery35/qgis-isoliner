# Isoliner — грид и изолинии (QGIS)

Плагин-провайдер Processing для **интерполяции точечных данных (кригинг 2D)** и
**построения изолиний и контурных полигонов** в QGIS. Порт инструмента Isoliner
(ArcGIS) в QGIS; ядро кригинга — алгоритм KB2D из GSLIB.

Сам плагин лежит в папке [`grid_isolines/`](grid_isolines/); подробное
руководство — [`grid_isolines/doc/Isoliner.pdf`](grid_isolines/doc/Isoliner.pdf).

## Возможности

- **2D Kriging (точки → растр)** — ординарный/простой кригинг по точечному слою;
  настраиваемая вариограмма (наггет + до 3 структур, анизотропия), обрезка по
  контуру скважин.
- **Изолинии из растра** — изолинии (линии) и контурные полигоны (пояса между
  изолиниями), границы которых **совпадают** с линиями; сглаживание поля и
  скругление линий.

Подходит для отметок пласта, мощностей, ФМС, химии и любых числовых атрибутов
скважин.

## Чем отличается от стандартных инструментов QGIS

В отличие от GDAL-контуринга и интерполяторов QGIS, Isoliner:

- даёт **2D-кригинг GSLIB KB2D** с полноценной моделью вариограммы (наггет,
  вложенные структуры, анизотропия) — этого нет в штатных IDW/TIN;
- строит залитые **контурные полигоны, границы которых точно совпадают с
  изолиниями** (без «ступенек» и дыр), что важно для геологических карт;
- ориентирован на рабочий процесс «скважины → поверхность → изолинии/полигоны».

## Установка

Из QGIS: **Модули → Управление и установка модулей → Установить из ZIP** — указать
архив с папкой `grid_isolines/`. Требования: QGIS 3.16+. Внешних зависимостей нет
(NumPy и GDAL входят в состав QGIS).

После установки инструменты — в панели **Обработка**: провайдер **«Isoliner»**,
группа **«Грид и изолинии»**.

## Тесты

Движок кригинга не зависит от QGIS и тестируется отдельно:

```bash
python grid_isolines/tests/test_kb2d.py
```
