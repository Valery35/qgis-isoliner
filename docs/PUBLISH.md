# Публикация выпусков Isoliner

Общий список площадок линейки, учётные записи и особенности площадок
ведутся в `C:\Dev\planetx-lite\doc\PUBLISH.md`. Здесь порядок для
Isoliner, отличия от PlanetX и журнал публикаций.

## Правила

- Выпуск объявляется на всех площадках списка, слово автора от
  4 ноября 2026 года «публикуй».
- Порядок: релизный проход (версия, changelog, руководства, PDF, архивы),
  затем GitHub и каталог, затем анонсы.
- Мелкие выпуски подряд объединяются в один анонс под последним номером.
- Каждая публикация проверяется после отправки, ссылка заносится в журнал.
- Тексты на русском - Telegram, ВК, Facebook. На английском - LinkedIn,
  X, OSGeo Discourse, Reddit.

## Площадки

| Площадка | Как публиковать |
|---|---|
| GitHub, выпуск | `releases/new?tag=<номер>`, архив `grid_isolines.zip`. Publish только когда в Assets появилась строка с размером, загрузка идёт около двух минут |
| Каталог QGIS | `plugins.qgis.org/plugins/grid_isolines/version/add/`, архив без тестов. После Save ждать смены страницы, второй раз не жать |
| Dropbox | Три архива без номера в `ИИ\Isoliner` |
| Сайт | Лендинг `site/isoliner_landing.html`, когда меняется состав инструментов. Номера версии на нём нет |
| Telegram, @qgis_isolines | Приложение Telegram, текст через буфер, пост один раз. Перед постом проверить, нет ли его уже |
| ВК, vk.ru/qgismodules | Статья и запись на стене со ссылкой на статью, у вопроса к читателям опрос с несколькими вариантами |
| OSGeo Discourse | Раздел General (id 4), тег qgis. Первая тема Isoliner ждёт одобрения модератора |
| LinkedIn | Пост на английском с хештегами |
| Facebook | Пост на русском на странице автора |
| X, @Valery35 | До 280 знаков, ссылка считается за 23 |
| Форум OSM | General talk по-английски, тег qgis. Повод - загрузка топоосновы из OSM и построение ЦМР по ней. Новичку две ссылки на пост и ограничение числа тем в первый день |
| Mastodon, en.osm.town | До 500 знаков, язык поста English |
| linux.org.ru | Новости, группа Open Source, текст на русском, ссылка обязательна, вопросов в тексте нет. Две темы за сутки, публикация после проверки модератором |
| Reddit r/QGIS, r/gis | Только автор, текст в `_social.md` |

Не используются для Isoliner: форум Rust, winget и AlternativeTo (только
PlanetX Lite).

Особенности:

- ВК. Кнопка «Создать пост» в редакторе статьи заполняет черновик записи
  ссылкой на статью. Если потом открыть «Пост» и вводить текст, ссылка
  склеивается с первым словом. Перед публикацией проверить начало текста.
- Telegram. Список чатов пересортировывается, когда приходят новые
  сообщения, а между действиями фокус возвращается окну Claude. Поэтому
  клик по строке списка может открыть не тот чат. 5 ноября 2026 года текст
  вставился в черновик личного чата (стёрт, не отправлен). Рабочий порядок:
  поиск «qgis_isolines» и Enter, затем одним пакетом клик в поле «Публикация»
  и Ctrl+V, снимок, сверка заголовка «Модули QGIS и PlanetX Lite», и только
  потом кнопка отправки.
- Reddit. Браузер помощника сайт не открывает (ограничение безопасности),
  публикует автор.
