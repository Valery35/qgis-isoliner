# Пресеты стилей Isoliner

Стили QGIS (.qml) для слоёв инструментов. Стили изолиний цепляются за поля
`ELEV` (значение) и `is_index` (1 = главная изолиния). Стиль векторов потока
цепляется за поля `az` (азимут потока) и `grad` (гидравлический градиент).

| файл | для чего |
|---|---|
| `iso_structure.qml` | структурные изолинии, гипсометрия. Главные толще и подписаны, промежуточные тоньше |
| `iso_depression.qml` | депрессионные изолинии. Бергштрихи (штрихи вниз по полю `dn_sign`) на главных изолиниях |
| `flow_arrows.qml` | векторы потока (точки) инструмента **Гидравлический градиент и направление потока**. Маркер-стрелка с поворотом по `az` и размером по `grad` |

Стили изолиний выбираются прямо в инструменте через **Стиль изолиний**. Стиль
векторов потока накладывается на слой векторов автоматически. Файлы здесь же на
случай ручной загрузки через Свойства слоя, Стиль, Загрузить стиль.

## Стрелки потока

`flow_arrows.qml` поворачивает маркер-стрелку по полю `az` (компасный азимут,
0 = север, по часовой) - стрелка смотрит туда, куда течёт вода. Размер
масштабируется по `grad` между минимумом и максимумом слоя, так что длиннее
стрелка там, где градиент круче. Размер задан в миллиметрах и не зависит от
масштаба карты. Если нужна классическая «квивер»-диаграмма со стрелками,
длина которых отложена в единицах карты, замените символ генератором геометрии:
`make_line($geometry, project($geometry, scale_linear("grad", minimum("grad"),
maximum("grad"), 50, 400), radians("az")))` и оформите линию стрелкой. Длину
(50..400) подберите под охват.

## Бергштрихи

Депрессионный стиль ставит штрихи в сторону понижения по полю `dn_sign`. Это
поле инструмент считает сам, когда выбран депрессионный стиль, отдельной галки
нет. Штрих реализован слоем HashLine (угол 0, то есть поперёк линии) со
смещением `@dn_sign * 1.3`. При необходимости подправь длину и шаг штриха под
масштаб карты в редакторе символа.
