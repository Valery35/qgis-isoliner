# Пресеты стилей изолиний Isoliner

Стили QGIS (.qml) для слоёв инструмента **Изолинии из растра**. Цепляются за
поля: `ELEV` (значение) и `is_index` (1 = главная изолиния).

| файл | для чего |
|---|---|
| `iso_structure.qml` | структурные изолинии, гипсометрия. Главные толще и подписаны, промежуточные тоньше |
| `iso_depression.qml` | депрессионные изолинии. Бергштрихи (штрихи вниз по полю `dn_sign`) на главных изолиниях |

Оба стиля выбираются прямо в инструменте через **Стиль изолиний** и
накладываются на слой автоматически. Файлы здесь же на случай ручной загрузки
через Свойства слоя, Стиль, Загрузить стиль.

## Бергштрихи

Депрессионный стиль ставит штрихи в сторону понижения по полю `dn_sign`. Это
поле инструмент считает сам, когда выбран депрессионный стиль, отдельной галки
нет. Штрих реализован слоем HashLine (угол 0, то есть поперёк линии) со
смещением `@dn_sign * 1.3`. При необходимости подправь длину и шаг штриха под
масштаб карты в редакторе символа.
