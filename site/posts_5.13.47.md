# Isoliner 5.13.47. Проекция на разрез в GeoPackage без потерь

Выпуск 5.13.47 исправляет потерю объектов при записи результата инструмента **4.07 Проекция объектов на разрез** в файл GeoPackage. Вместе с ним выходят правки 5.13.46, после которых английский интерфейс модуля не содержит русского текста.

## Что происходило с 4.07

Инструмент 4.07 выносит точки, линии и полигоны на чертёж разреза. Определение разреза может содержать несколько линий, и тогда каждый объект выносится на каждый разрез, в коридор которого попадает. Один исходный объект даёт в результате несколько записей, по одной на разрез.

В GeoPackage у каждой записи есть ключ fid, и QGIS показывает его обычным полем слоя. Инструмент переносил поля исходного слоя в результат вместе с этим полем. Первая запись объекта сохранялась, а вторая и следующие получали тот же ключ, и GeoPackage их отвергал. Сообщение об этом попадало только в журнал GDAL, окно инструмента завершалось без ошибки.

На демо-разрезе с тремя линиями в файл записывалось 27 объектов из 81. Временный слой при этом был полным, поэтому при проверке во временном слое ошибка не проявлялась.

## Что изменилось

Поле fid исходного слоя переходит в результат под именем fid_2. Номер исходного объекта сохраняется, а ключ записи в файле назначается заново. Тот же порядок действует во всех инструментах, которые переносят поля исходного слоя, в том числе в 4.08, 4.12, 6.06 и в разделении горизонталей 2.08. Выбранные для переноса поля с именем fid получают приставку src_.

Если результат 4.07 сохранялся в GeoPackage по определению с несколькими разрезами, его нужно построить заново. В старом файле на втором и следующих разрезах не хватает объектов.

## Английский интерфейс

С выпуска 5.13.46 английский интерфейс не показывает русский текст. Слои окна **Basemap** и их стили названы по-английски (ESRI World Imagery, OpenTopoMap и другие), примечание о полупрозрачном стиле из списка убрано, сам стиль Semi-transparent выбирается в свойствах слоя. Переведены сообщения расчётных модулей в журнале, подписи параметров 5.03, имена выходов 5.02 и 8.01, подписи на разрезах и в отчёте створа, имена в демо-данных. Индексы пластов (АБ, КрII, ПЦТ и другие) остаются как в стратиграфии.

## Установка

Расчёты, параметры и стили слоёв не изменились. Версия ждёт проверки в каталоге QGIS и после неё придёт обновлением модуля. Архив уже лежит в выпуске на GitHub и ставится через **Установить из ZIP**.
